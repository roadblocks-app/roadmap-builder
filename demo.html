🚀 Roadblocks.app Demo

Welcome to the drag-and-drop roadmap builder! This demo shows you how to use the app.

📝 Step 1: Try the Text Parser

Copy this sample roadmap text and paste it into the app:

1. Research market trends and competitors 2. Create wireframes and user stories 3. Develop MVP with core features 4. Test with beta users 5. Launch public version 6. Gather user feedback 7. Iterate and improve

🎯 Step 2: Features to Try

  • Drag & Drop: Rearrange milestones by dragging them
  • Edit Inline: Click on titles, descriptions, and dates to edit them
  • Toggle Direction: Switch between bottom-to-top and top-to-bottom
  • Categories: Assign categories to milestones
  • Checkboxes: Mark completed milestones
  • Export PDF: Generate A4 PDF with checklist column

📱 Step 3: PWA Features

  • Install: Add to home screen on mobile devices
  • Offline: Works without internet connection
  • Responsive: Adapts to different screen sizes
